1. O que é um provider de autenticação?
    - Um provider de autenticação é uma entidade que ofereçe serviços de autenticação.
Ele abstrai a complexidade de implementar do zero, permitindo que você se concentre em tarefas mais importantes. 
2. Qual é a diferença entre o e-mail do usuário e o UID do usuário?
    - A diferença é que o email pode ser lido por qualquer um, o endereço público de contato com o usuário, já o UID é um identificador único atribuido a cada usuário pelo sistema, e é essencial para a gestão de dados do usuário.
3. Por que o UID é melhor do que o e-mail para nomear pastas e documentos internos?
    - É melhor porque é unico para cada usuário e é criptografado e gerenciado pelo sistema, o que deixa mais seguro, já que outros usuário conseguem ter acesso ao email público, porém o UID continua secreto.
